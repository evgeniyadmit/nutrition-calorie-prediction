# Нейросеть для предсказания калорийности блюд

Итоговый проект по задаче мультимодальной регрессии. Цель модели — предсказать общую калорийность блюда по фотографии, списку ингредиентов и массе порции.

## Результат

Основная метрика — MAE. Целевое значение проекта: **MAE < 50**. В сохранённом выполненном ноутбуке итоговая модель получила **Test MAE ≈ 39 ккал**.

## Модель

Модель объединяет три источника признаков:

- текст ингредиентов: `distilbert-base-uncased`;
- изображение: предобученный `ResNet18`;
- масса блюда: небольшой MLP-блок.

Полученные представления объединяются и передаются в регрессионную голову с одним выходным нейроном без функции активации. Для обучения используется `L1Loss`.

## Запуск

Основной сценарий работы и результаты эксперимента находятся в `notebook.ipynb`. В ноутбуке сохранены результаты EDA, процесс обучения, график train/validation MAE, итоговая оценка на тестовой выборке и анализ пяти объектов с наибольшей абсолютной ошибкой.

Основные компоненты вынесены в `scripts/`: подготовка данных, архитектура модели, конфигурация, обучение и оценка.

Для установки зависимостей:

```bash
pip install -r requirements.txt
```

Воспроизводимый запуск обучения с передачей конфигурационного файла:

```bash
python train.py --config scripts/config.py
```

`train.py` загружает конфигурацию, подготавливает таблицы и разбиение, создаёт DataLoader и модель, после чего запускает тот же цикл обучения, который используется в ноутбуке.

> Конфигурация исходного эксперимента рассчитана на Google Colab: путь к данным `/content/data`, а лучший checkpoint сохраняется в Google Drive. При запуске в другом окружении пути `DATA_DIR` и `MODEL_PATH` в `scripts/config.py` нужно изменить.
